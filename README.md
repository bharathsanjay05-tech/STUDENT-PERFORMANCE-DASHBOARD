# STUDENT-PERFORMANCE-DASHBOARD

This project presents an interactive Student Performance Dashboard designed to analyze and understand student academic performance across different demographic and educational factors. The dashboard provides an overview of 1,000 students, with key performance indicators for average Mathematics, Reading, and Writing scores.

The dashboard includes visualizations for academic performance by gender, Mathematics performance by parental education level, and the relationship between Reading and Writing scores across different groups. These visualizations help identify performance patterns and differences among students based on gender and parental education background.

A detailed student performance breakdown by demographics is also provided, covering race/ethnicity, gender, student count, Mathematics score, Reading score, and Writing score. Interactive filters such as Gender, Parental Level of Education, Lunch Type, and Test Preparation Course allow users to explore specific student segments and analyze their performance in greater detail.

The dashboard was created to transform student performance data into meaningful and easy-to-understand visual insights. It can support academic analysis, performance monitoring, demographic comparisons, and educational planning, while demonstrating practical skills in data visualization, dashboard design, data analysis, and interactive reporting.
